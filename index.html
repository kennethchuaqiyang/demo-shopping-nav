Demo data (for automation testing only): each tab leads to its own page via a different navigation mechanism (same-tab location.href, window.open() with no size, window.open() with width/height/left/top). Built to test a page-discovery/crawl mode that has to find pages reachable each of these three ways - a plain list of known URLs (today's capture mode) can't discover any of them on its own. Each click is counted in localStorage; see counter.html.
